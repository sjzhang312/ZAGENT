# 现代技能包支持：附属资源落盘沙箱 + 四工具交互

## 设计核心

技能包完整解压到**沙箱目录** `{workspace}/skills/{技能名}/`（即 `ai-workspace/skills/`）。这样技能的参考文档、脚本天然落在 read/write/edit/bash 四工具的作用域内——模型在问答中对技能文件调用工具，问答中心现有的工具状态帧（● read x / ● bash x）自动展示交互过程。数据库只存元数据 + 资源清单（表已建好），正文不进库。

## 改动清单

### 后端（zagent-ai 模块）

1. **`domain/AiSkillResource.java`**（新增）：resourceId / skillId / relPath / fileSize / createTime
2. **`domain/AiSkill.java`**：加 transient 字段 `List<AiSkillResource> resources`（详情接口回填用，不入库）
3. **`mapper/AiSkillResourceMapper.java` + XML**（新增）：selectBySkillId / insertBatch / deleteBySkillId
4. **`tools/SkillStorageService.java`**（新增，复用 `zagent.ai.workspace` 配置）：
   - `extract(zipBytes, skillName, stripPrefix)`：清旧重建 `skills/{name}/`，全量安全解压（防 zip-slip）
   - `readMain(skillName)`：读 SKILL.md 正文；`delete(skillName)`：递归删目录；`skillDir/exists`
5. **`AiSkillServiceImpl` 重写导入与联动**：
   - 导入：沿用两阶段扫描（SKILL.md 优先规则不变）→ 确定 zip 内技能包根前缀 → **全量解压落盘** → 元数据 upsert（**content 置空**）→ 资源清单（除 SKILL.md 外全部文件）写入 ai_skill_resource → 返回明细含资源数
   - 散装单 md：不落盘，content 照旧存库（兼容）
   - `deleteAiSkillByIds`：同时删资源记录 + 删沙箱目录
   - `selectAiSkillById`：有落盘目录则从 SKILL.md 回填 content + 附 resources 列表
   - `updateAiSkill`：包技能编辑正文时同步写回 SKILL.md 文件（防库/文件脱节）
6. **`AiChatServiceImpl` 技能注入改造**（响应用户"四种工具都要"）：启用的技能若有落盘目录，注入 = 描述 + SKILL.md 正文 + 资源清单 + **四工具使用指引**：
   - `read skills/{name}/references/xxx.md` 查看参考文档
   - `bash python skills/{name}/scripts/xxx.py` 执行技能脚本
   - `write` 产出结果文件（如生成的 .drawio）
   - `edit` 基于技能模板精确修改
   - 指引按智能体 `enabledTools` 动态过滤（没启用的工具不写，避免模型调用不存在的工具）；纯文本技能（手动录入）沿用现有拼接

### 前端

7. **`api/ai/skill.ts`**：AiSkill 接口加 `resources` 字段
8. **`views/ai/skill/index.vue`**：查看/编辑对话框底部加附属资源表格（相对路径 + 大小）；列表"内容"列对包技能显示提示文案
